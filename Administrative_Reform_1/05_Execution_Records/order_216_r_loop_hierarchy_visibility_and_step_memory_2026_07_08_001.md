# ORDER 216 Execution Record: R Loop Hierarchy Visibility And Step Memory

## Status

Implemented and locally verified on 2026-07-08.

## Goal

Make Vessel R traversal preserve per-step navigation memory so that R2/R3 do not lose what the previous graph step selected, inspected, exposed, and promoted.

## Implemented Changes

- Added `RLoopVesselStepMemoryPacketFrame` in `songryeon_core/loops/r_loop_vessel_one_step.py`.
- R traversal now records one code-generated step memory packet per completed R2/R3 step.
- The next R2 and R3 calls receive `previous_r_step_memory_packet` when available.
- R3 receives the selected node as inspected material, while child candidates are exposed as preview-only navigation cards.
- Step memory preserves visible child candidate node IDs, promoted next candidate node IDs, R3 status signals, continuation status, remaining budgets, and raw/terminal material counts.
- `RLoopVesselTraverseResultFrame` now records `step_memory_packet_ids`.
- `RLoopVesselActivityLedgerFrame` now records `step_memory_packet_ids` and includes `step_memory` activity records.
- R2/R3 prompts were updated to explain that previous step memory is navigation memory, not a selectable candidate list or raw material grant.

## Meta-Information Boundary

- Step memory is generated by `CODE:NODE_0_R_VESSEL_STEP_MEMORY`.
- Step memory uses `info_class=absolute`.
- Step memory uses `semantic_judgement_status=not_run`.
- Code records traversal facts and candidate visibility only.
- R2 still performs semantic selection.
- R3 still performs sufficiency/granularity/branch status judgment.

## Live Test Follow-Up

After the first live Vessel R traversal test, `RLoopVesselTraverseResultFrame`
raised `selected path mismatch`.

Cause:

- A later R2 step can record a `none_selected` selection frame.
- That frame must remain in `r2_selection_frame_ids`.
- But it has no selected graph node, so it should not add an entry to
  `selected_graph_node_ids`.

Fix:

- The traverse result validator now rejects only impossible over-counts where
  selected path entries exceed R2 selection frames.
- ORDER 215 path preservation tests now include a `none_selected` case.
